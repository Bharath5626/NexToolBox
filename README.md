🧰 NexToolBox
A clean and responsive multi-tool web app featuring essential utilities like a Temporary Email Generator and Random Password Generator. Designed to be practical, minimal, and beginner-friendly.

🌐 Live Demo
🔗 https://bharath5626.github.io/NexToolBox/

🚀 Features
✅ Temp Mail Generator

Generate temporary/disposable email addresses
View and copy generated addresses
✅ Random Password Generator

Generate strong passwords with mixed characters
Select password length dynamically
🎨 User-Friendly UI

Mobile responsive
Clean layout with clear sections
Modern design using CSS
🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
API: Temp Mail API via RapidAPI
Hosting: GitHub Pages
