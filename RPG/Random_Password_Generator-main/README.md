# 🔐 Random Password Generator

A simple and responsive web application to generate strong, secure random passwords of customizable lengths.


### 🔗 [Live Demo](https://bharath5626.github.io/Random_Password_Generator/) 

---

## 🚀 Features
- Generate random passwords instantly
- Choose your desired password length
- Includes uppercase, lowercase, numbers, and symbols
- Fully responsive design

---

## 🛠️ Tech Stack
- **HTML**
- **CSS**
- **JavaScript**

---

## ⚙️ How to Use
1. Open the app
2. Set the password length
3. Click "Generate Password"
4. Copy the password and use it securely!
